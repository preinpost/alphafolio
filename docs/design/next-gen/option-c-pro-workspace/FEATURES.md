# 실제 앱 기능 인벤토리 (Option C 범위 기준)

출처: `apps/web/src` (App.tsx `NAV`, 각 Page·하위 컴포넌트), `packages/protocol/src`.
이 시안은 **아래 목록에 있는 것만** 그린다. 새 기능은 없다.

## 공통 셸 (App.tsx)
- 메뉴 5개: **챗 · 투자 · 일지 · 가계부 · 설정** (모바일 하단 탭바, 데스크톱 사이드바)
- 사이드바: 로고(=챗 홈), 새 대화, 최근 대화(오늘/어제/지난 7일/지난 30일/이전, 응답 중·새 답 점, 삭제), 연결 상태·모델·버전, 사용자·테마 전환·로그아웃
- 모바일 챗: 햄버거 → 드로어(같은 메뉴 + 최근 대화)
- 업데이트 배너, 토스트

## 챗 (ChatPage · MessageList · Composer · cards/*)
- 상단: 대화 제목(없으면 "새 대화") + 모델명(mono), 새 대화 버튼
- 빈 화면 제안 4개: 삼성전자 얼마야 / 내 보유 종목 점검해줘 / 이번 달 지출 얼마나 썼어? / 오늘 증시 주도주 어디야?
- 메시지: 사용자 말풍선(이미지 첨부 포함), AI 답(Markdown — 표 포함), 툴 칩(실행 중·완료·오류 문구), 생각 중 표시, 답 복사, 오류 notice, 맨 아래로 버튼
- 컴포저: 텍스트, 이미지 첨부(썸네일·빼기), 보내기/응답 중지, 면책 문구
- **확인 카드만** 카드로 그린다 (조회 결과는 텍스트): 만료 바·남은 시간, 닫기/실행, 접수 중·완료·실패·만료·닫음
  - 국내 주문(order-preview) · 정정/취소(order-change) · 조건부(OCO/OTO) · Binance 주문 · 지갑 이동 · 선물 · 감시/자동 매매 켜기(watch-confirm, 과거 신호 미리보기 포함) · 외부 MCP 쓰기
  - 주문 카드에 "매매 근거 (선택) — 매매일지에 남습니다" 입력

## 투자 (PortfolioPage · portfolio/*)
- 새로고침, 오류/경고 notice
- 총자산(원화 환산) 큰 숫자 · 전일 대비 · 이번 달 · 주식 평가손익 · 추이 차트(1개월/3개월/6개월/1년)
- 미체결 주문(줄마다 취소)
- 보유 자산: 계좌별/종목별 보기, 검색, 종류 칩(전체·국내주식·해외주식·코인·직접 입력), 정렬(평가금액·수익률·이름), 계좌 필터 pill, 1달러 미만 코인 접기/펼치기, 직접 입력 자산 추가·수정(ManualAssetEditor: 이름·종류·금액·통화·메모, 삭제)
- 자산 배분 막대(국내주식·해외주식·코인·현금성·기타)
- 계좌(누르면 해당 계좌만, 상태 배지: 일부 누락·조회 실패·제외)
- 화폐별(원화·달러·코인 USDT) + 예수금
- 시세 조회(종목코드/티커 → 이름·가격·전일 대비 → "챗에서 분석·주문 준비하기")

## 일지 (JournalPage · journal/*)
- 체결 가져오기, 직접 기록
- 기간(30일·90일·올해·전체), 챗 안내 문구
- 요약: 기간 매매 N건, 매수·매도·확인 전, 기록 습관 3줄(근거·손절가·회고 비율)
- 태그 칩(누르면 그 태그만), 감정 분포(비율·건수)
- 목록: 검색, 칩(전체·근거 없음·매수·매도·체결 확인 전), 날짜별 묶음, 행(매수/매도 태그, 종목·티커, 수량·가격, 계좌·출처, 상태 배지, 근거·태그, 금액·실현손익·감정)
- 기록 시트: 체결 사실(고칠 수 없음 — 체결·날짜·계좌·실현손익·수수료·주문·감시·슬리피지, "주문을 준비한 대화 보기") 또는 직접 기록 칸, 근거·목표가·손절가·태그·감정(차분·확신·불안·조급·욕심·충동)·회고, 삭제/취소/저장

## 가계부 (LedgerPage · ledger/* · LedgerSettings)
- 월 이동, 기록 추가
- 가계부 선택(여러 개), 범위(전체·내 기록), 관리·초대, 챗 안내 문구
- 이달 지출 큰 숫자 · 수입 · 예산 남음 · 분류 막대 · 분류 행(누르면 그 분류만)
- 내역: 검색, 분류 칩, 날짜별(그날 지출 합), 행(가맹점·분류·사람·메모·"챗" 출처)
- 받은 초대(수락·거절, 만료일), 예산(분류별 사용률·초과), 사람별 지출
- 기록 시트: 지출/수입, 금액, 가맹점, 분류, 날짜, 메모, 삭제/취소/저장
- 관리: 이름 변경, 멤버(소유권 넘기기·내보내기), 초대(대기 중·취소), 새 가계부, 백업(JSON 내보내기), 삭제(이름 입력 확인), 나가기

## 설정 (SettingsPage · AccountSettings · McpSettings · WatchSettings)
- 탭: 계정 · 연결 · MCP 서버 · 감시 · AI 모델 · 화면 · 관리자(관리자만)
- 계정: 비밀번호 바꾸기, 다른 기기 모두 로그아웃
- 연결: 키 그룹(증권 KIS·증권 토스·코인 Binance·데이터 해외·뉴스 네이버·알림 텔레그램) — 출처 배지(내 설정·서버 env·미설정), 새 값으로 교체·지우기, 텔레그램 연결 테스트
- MCP 서버: 연결한 서버(상태·연결·연결 테스트·연결 해제·삭제), 프리셋 추가·직접 추가 폼, 툴 목록(서버 고르기·검색·판정 필터·쓰기 배지), 삭제 확인 시트
- 감시: 자동 매매 하루 한도(국장 원·미장 $·코인 USDT), 감시 목록(상태·조건·자동 매매 주문·범위 전략 상태·발동/만료·일시정지/다시 켜기/삭제·만든 대화 열기), 비상 정지, 최근 자동 매매, 최근 기록
- AI 모델: OpenRouter·Anthropic 키
- 화면: 테마(라이트·다크·시스템)
- 관리자: 서버 DB(연결 테스트), 초대 코드 발급·목록, 계정(임시 비밀번호·비활성화)

## 이 시안에서 뺀 것
- 실제 앱에도 있는 단축키 카드(설정 → 화면)·사이드바 ⌘1–5 표기: 사용자 요청으로 제외
- 이전 시안이 만든 기능 전부: ⌘K 팔레트·슬래시 명령, 상태 바, 상단 시세 티커, what-if 슬라이더, 손익 기여도, 히트맵, 백테스트, 10단 호가, 차트 주문/손절선, 별도 주문 화면, 가계부 한 줄 파서·지출 달력, 감시 백테스트·알림 히스토리 화면

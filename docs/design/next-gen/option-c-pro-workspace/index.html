Pro Workspace — 폰에서 먼저, 촘촘하게

지금 앱의 메뉴 다섯 개(챗 · 투자 · 일지 · 가계부 · 설정)와 각 메뉴가 실제로 하는 일만 그대로 옮겼습니다. 기본 화면은 390px iOS(Capacitor)이고, 데스크톱은 같은 화면을 넓혀 레일 + 2단 + 옆 챗 패널로 펼칩니다. 다크 우선, 표 수준의 정보 밀도, AI·초점은 보라색 하나로만 표시합니다.

모바일 우선 5탭

하단 탭바에 실제 메뉴 5개. 44px 이상 터치 영역, 위쪽 고정 헤더에 그 화면의 행동(새로고침·기록·월 이동)만.

숫자가 주인공

화면당 큰 숫자 하나(총자산·매매 수·이달 지출). Pretendard 탭 숫자 정렬, 티커·조건식은 JetBrains Mono.

챗은 맥락 안에

각 화면의 “챗에서 이렇게 말해도 됩니다” 안내는 보라색 카드로. 넓은 화면에서는 같은 대화가 오른쪽 패널에 붙습니다.

안전한 확정

주문 확인 카드는 만료 바 + 길게 눌러 확정. 길게 누르기가 어려우면 한 번 누르는 버튼으로 바꿀 수 있습니다(키보드·스크린리더는 바로 확정).

화면 — 각 링크는 폰·데스크톱 모두 반응형

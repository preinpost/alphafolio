Agent Canvas

지금 앱의 메뉴 5개(챗·투자·일지·가계부·설정)와 기능은 그대로 두고, 옷만 바꿉니다. 웜 뉴트럴 바탕에 세리프 제목, 보라색 에이전트 포인트. 챗은 지금처럼 답을 글과 표로 주고, 주문·감시는 확인 카드로 묻습니다. 아이폰(390px)이 기준이고 데스크톱은 그 화면을 넓힌 것입니다.

데모 시작 →기능 인벤토리
01 · 챗

새 대화

제안 4개(시세·포트폴리오·가계부·시장), 이미지 첨부 입력창, 모바일 대화 목록 드로어.
02 · 챗

대화 · 감시 확인 카드

도구 호출 칩, 표가 있는 답변, 감시 켜기 확인 카드(지난 30일 미리보기), 응답 중 상태.
03 · 챗

주문 확인 카드

증권사 배지·남은 확인 시간·매매 근거 메모. 밀어서 주문 + 두 번 누르는 버튼 대안.
04 · 투자

투자

총자산·추이, 미체결 주문, 보유 자산(계좌별/종목별·검색·정렬), 직접 입력 자산, 배분·계좌·화폐별, 시세 조회.
05 · 일지

매매일지

가져오기·직접 기록, 기간, 근거 없음 필터, 기록 습관·태그·감정, 기록 시트.
06 · 가계부

가계부

월 이동, 가계부 선택·범위, 이달 지출·분류, 내역, 예산, 사람별, 초대, 관리 시트.
07 · 설정

설정

계정 · 연결 · MCP 서버 · 감시 · AI 모델 · 화면 · 관리자 — 지금 앱과 같은 7개 탭.
08 · 공통

감시 알림 토스트

감시가 발동하면 어느 화면에서든 위에서 내려오는 알림 → 설정의 감시로.

원칙

1
기능은 지금 앱 그대로새 메뉴·새 기능 없음. 메뉴마다 하는 일은 FEATURES.md 와 1:1.
2
에이전트는 챗에입력창은 챗 화면에만. 다른 화면은 지금 앱의 안내 문구(“챗에서 … 처럼 말해도 됩니다”)를 챗으로 가는 링크로.
3
실행은 반드시 사람이챗의 카드는 확인 카드뿐. 남은 확인 시간을 보여 주고, 밀어서 확인 또는 두 번 누르기.
4
모바일이 먼저390px 하단 탭바·바텀 시트가 기준. 데스크톱은 사이드바 + 두 열로 넓힐 뿐.

시스템

상승 +2.82%하락 −1.37%에이전트일부 누락체결

Pretendard Variable(본문·숫자) · Instrument Serif + Noto Serif KR(제목) · JetBrains Mono(도구 호출·코드). 한국식 빨강=상승 / 파랑=하락, 음수는 “−”. 라이트·다크·시스템. 화면당 큰 숫자 하나.

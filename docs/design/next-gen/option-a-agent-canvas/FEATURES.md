# 실제 앱 기능 인벤토리 (Option A 범위 기준)

출처: `apps/web/src` (App.tsx NAV, components/*, cards/*) · `packages/protocol`.
이 제안은 **아래 목록에 있는 기능만** 그립니다. 목록에 없는 기능은 화면에 넣지 않습니다.

## 셸 (App.tsx)
- 메뉴 5개: **챗 · 투자 · 일지 · 가계부 · 설정** (모바일 하단 탭바 / 데스크톱 왼쪽 사이드바)
- 사이드바: 로고(→챗), 새 대화, 최근 대화 목록(안 읽음 표시·삭제), 사용자(관리자/사용자), 테마 전환, 로그아웃
- 모바일 챗: 왼쪽 가장자리 스와이프/메뉴 버튼 → 대화 목록 드로어
- 상단 연결 상태(모델 이름 / 연결 중…), 새 버전 안내 배너
- 감시 이벤트 토스트(발동·늦은 발동·만료·비상 정지·주문·주문 안 함) → 열기

## 챗 (ChatPage · MessageList · Composer · Markdown · cards/*)
- 빈 대화 제안 4개: 삼성전자 얼마야 / 내 보유 종목 점검해줘 / 이번 달 지출 얼마나 썼어? / 오늘 증시 주도주 어디야?
- 답변은 **마크다운 텍스트**(표 포함). 조회 결과는 카드로 그리지 않음
- 도구 호출 칩(진행 중·오류), 생각 중 한 줄, 메시지 복사, 맨 아래로
- 입력창: 이미지 첨부(최대 장수 제한), 보내기, 응답 중지, 응답 중에도 이어 입력, 면책 문구
- **확인 카드만** 존재 (사람이 눌러야 실행):
  - order-preview-card (매수/매도 주문 확인 · 증권사 배지 · 남은 확인 시간 · 매매 근거 메모 → 매매일지)
  - order-change-card (정정/취소), conditional-order-card (OCO·OTO·단일 조건)
  - binance-order-card, binance-transfer-card(지갑 이동), binance-futures-card(선물)
  - watch-confirm-card (감시 켜기 / 자동 매매 켜기 · 지난 N일이었다면 몇 번 울림)
  - mcp-confirm-card (외부 MCP 쓰기 툴 실행)
  - 상태: 대기 → 접수 중 → 완료/실패 · 만료 · 닫음

## 투자 (PortfolioPage · portfolio/*)
- 새로고침
- 총자산(원화 환산) 큰 숫자 · 전일 대비 · 이번 달 · 주식 평가손익 · 추이 차트(1개월/3개월/6개월/1년)
- 미체결 주문(줄마다 취소)
- 보유 자산: 계좌별/종목별 보기, 종목 검색, 자산 종류 칩(전체·국내주식·해외주식·코인·직접 입력), 정렬(평가금액·수익률·이름), 1달러 미만 코인 접기/펼치기
- 직접 입력 자산(예금·현금/연금/부동산/기타 투자/기타) 추가·수정·삭제 — 목록 행 자리에서 펼침
- 자산 배분 막대(국내주식·해외주식·코인·현금성·기타)
- 계좌(누르면 그 계좌만 · 일부 누락/조회 실패 배지)
- 화폐별(원화·달러·코인 USDT) + 예수금
- 시세 조회(종목코드/티커 → 현재가·전일 대비 → "챗에서 분석·주문 준비하기")

## 일지 (JournalPage · journal/*)
- 체결 가져오기, 직접 기록
- 기간: 30일 / 90일 / 올해 / 전체
- 매매 목록(날짜별), 검색(종목·근거), 칩(전체·근거 없음·매수·매도·체결 확인 전), 태그 필터
- 요약: 기간 매매 수 · 매수/매도/확인 전 · 기록 습관(근거·손절가·회고 비율)
- 태그 분포, 감정 분포
- 기록 시트: 체결 사실(고칠 수 없음, 주문을 준비한 대화 보기) / 직접 기록 칸 + 근거·목표가·손절가·태그·감정(차분·확신·불안·조급·욕심·충동)·회고, 삭제
- 챗에서 "어제 산 삼성전자 근거 적어줘"로도 기록 (안내 문구)
- **없음**: AI 회고 초안, 매매 패턴 분석, 손익 계산(손익은 실현손익 표시만)

## 가계부 (LedgerPage · ledger/* · LedgerSettings)
- 월 이동(이전/다음 달), 기록 추가
- 가계부 선택(여러 개), 범위(전체 / 내 기록), 관리·초대
- 이달 지출 큰 숫자 · 수입 · 예산 남음 · 분류 비중 막대 · 분류별(누르면 그 분류만)
- 내역(날짜별 지출 합계, 챗 출처 표시), 검색(가맹점·메모), 분류 칩
- 예산(분류별 사용률·초과) — 설정은 챗에서 "식비 예산 30만원"
- 사람별 지출(멤버 2명 이상)
- 받은 초대 수락/거절
- 관리: 이름 변경, 기본 가계부, 멤버(소유권 넘기기·내보내기), 초대(상대 ID), 새 가계부, 백업, 삭제/나가기
- 기록 시트: 지출/수입, 금액, 가맹점·내용, 분류, 날짜, 메모, 삭제
- 챗에서 "어제 김밥천국 8천원"으로도 기록 (안내 문구)
- **없음**: 음성 입력, 자연어 시트, 6개월 추이, 자동 분류 배지

## 설정 (SettingsPage · AccountSettings · McpSettings · WatchSettings)
- 탭: 계정 · 연결 · MCP 서버 · 감시 · AI 모델 · 화면 · 관리자(관리자만)
- 계정: 비밀번호 바꾸기, 이 기기만 남기고 모두 로그아웃
- 연결: 증권(KIS·토스)·Binance·뉴스 키, 알림(텔레그램) + 연결 테스트 — 출처 배지(내 설정/서버 env/미설정), 새 값으로 교체, 삭제
- MCP 서버: 연결한 서버(연결 테스트·삭제), 추가(이름·주소·인증 OAuth/Bearer/없음), 툴 목록(검색·판정: 바로 실행/확인 카드, 다시 받기)
- 감시: 자동 매매 한도(국장 원·미장 $·코인 USDT), 감시 목록(일시정지·다시 켜기·삭제), 비상 정지, 최근 자동 매매, 최근 기록
- AI 모델: LLM 키 (비우면 서버 기본 계정)
- 화면: 테마(라이트/다크/시스템) — **단축키 섹션은 이 제안에서 제외**
- 관리자: 초대 코드 발급(메모·유효 기간 1/7/30일), 계정 관리(임시 비밀번호·비활성화), 서버 DB·설정 출처·서버 버전·모델

# 실제 앱 기능 인벤토리 (Proposal B 범위 기준)

출처: `apps/web/src` (App.tsx `NAV`, 각 Page·하위 컴포넌트, chat cards), `packages/protocol`.
이 제안서는 **아래 목록에 있는 것만** 새 시각 언어로 다시 그린다. 새 기능은 없다.

메뉴(App.tsx `NAV`) — 순서 그대로: **챗 · 투자 · 일지 · 가계부 · 설정**

## 현재 앱 레이아웃 (셸) — 이 제안은 이 틀을 그대로 따른다

출처: `App.tsx` (`Shell` · `Sidebar` · `ConversationList` · `useDrawerSwipe`), `Topbar.tsx`, `ChatPage.tsx`, `SettingsPage.tsx`, `styles.css` 셸 규칙.

**분기점**: 767/768px (사이드바 ↔ 탭바), 860px (설정 탭 세로 ↔ 가로), 959px·1100px (화면 안 두 칸 → 한 칸).

**데스크톱 (≥768px)** — `grid: 256px 사이드바 | 본문`
- 사이드바(위→아래): 로고 "AlphaFolio"(= 챗으로) · **[새 대화]** · 메뉴 5개(챗·투자·일지·가계부·설정, ⌘1~5 표시) · **"최근 대화"** 목록 · 아래 상태줄(연결 LED·모델명·버전, 새 버전이면 "받기") · 나(아바타·아이디·관리자/사용자, 테마 전환, 로그아웃)
- 최근 대화: 최대 50개, 마지막 수정일로 묶음(오늘·어제·지난 7일·지난 30일·이전), 보고 있는 대화 강조, **응답 중** 점(깜빡임)·**새 답** 점(안 본 사이 끝난 답, 굵게), 휴지통(마우스는 올린 행만, 터치는 보고 있는 대화만) → 확인 후 삭제(응답 중이면 "작성 중인 답도 멈춥니다")
- 본문: 화면마다 자기 **topbar**(56px, 아래 테두리) — 제목 · 보조 문구(데스크톱만) · 오른쪽 동작. 그 아래 스크롤되는 페이지(`.wrap` 최대 1240px, 설정은 1040px)
- 대화상자(`dialog.sheet`): 데스크톱은 가운데 모달, 모바일은 바텀시트. 플로팅 버튼(FAB)은 **없다**

**모바일 (<768px)**
- 사이드바 숨김 → **하단 탭바**(5개, 아이콘+라벨)
- **대화 기록은 왼쪽 드로어**: 챗 topbar 왼쪽 ☰(메뉴 열기) 또는 화면 왼쪽 가장자리 24px 스와이프로 연다. 내용 = "AlphaFolio" + 닫기 · [새 대화] · 메뉴 5개 · 최근 대화. 배경 누르기·왼쪽으로 밀기·**Esc**로 닫힘, 데스크톱 폭이 되면 자동으로 닫힘. 다른 화면에서는 가장자리 스와이프가 열지 않는다
- 대화를 읽는 중(메시지 있음)에는 **탭바를 접는다** — 화면 이동은 드로어가 맡는다. 빈 새 대화 화면에서는 탭바가 보인다
- topbar 52px, 보조 문구 숨김, 버튼 라벨은 아이콘만

**화면별 topbar**
- 챗: [☰ 모바일만] 대화 제목(저장 전엔 "새 대화") · 모델명(보조) · 오른쪽 [새 대화(연필)]. 아래 메시지 목록, 맨 아래 입력창(가운데 정렬, 면책 문구)
- 투자: "투자" · 계좌 수·갱신 시각 · [새로고침]
- 일지: "매매일지" · 안내 문구 · [가져오기] [기록]
- 가계부: "가계부"(데스크톱만) · ‹ 년월 › · [기록 추가]
- 설정: "설정" — 본문 왼쪽 세로 탭(계정·연결·MCP 서버·감시·AI 모델·화면 | 관리자), 860px 이하는 가로 스크롤 탭

## 1. 챗 (`chat`) — ChatPage · MessageList · Composer · Markdown · cards/*

- 새 대화 / 최근 대화 목록 (데스크톱 사이드바, 모바일은 메뉴 드로어 — 위 "현재 앱 레이아웃")
- 빈 대화 환영 화면: "무엇을 도와드릴까요?" + 추천 질문 4개
  - 삼성전자 얼마야(시세 조회) · 내 보유 종목 점검해줘(포트폴리오) · 이번 달 지출 얼마나 썼어?(가계부) · 오늘 증시 주도주 어디야?(시장 요약)
- 메시지 목록: 사용자 말풍선(첨부 이미지 포함), 에이전트 턴(마크다운·표), 실행 중인 툴 표시, 생각 중 표시
- 답변 복사 버튼, "맨 아래로" 버튼
- 입력창: 텍스트, 이미지 첨부(장수 제한), 보내기 / 응답 중지, 응답 중에도 이어서 입력, 면책 문구
- 조회 결과(시세·보유·가계부 등)는 **카드 없이 답변 텍스트**로만 보인다
- **확인 카드** (사람이 [확인]을 눌러야 실행되는 유일한 경로, 만료 시간 막대·남은 시간, 결과/만료/닫음 상태)
  - 주문 확인 (한국투자·토스 주식) — 매수/매도, 지정가/시장가, 수량, 금액, **매매 근거(선택, 일지에 남음)**
  - 주문 정정 / 주문 취소 확인
  - 조건주문 (단일 / 익절·손절 OCO / 매수 후 매도 OTO) 등록·수정·취소
  - Binance 현물 주문 (주문·취소·재주문·OCO·OTO·미체결 전체 취소), 가격 불리/유리 표시
  - Binance 지갑 이동 (현물·선물·펀딩·Earn)
  - Binance USDⓈ-M 선물 (진입·청산·익절손절·취소·전체 취소·종목 설정; 레버리지·격리/교차·예상 청산가·손절 유무)
  - 감시 켜기 / 자동 매매 켜기 — 조건 한 줄, "지난 N일이었다면 N번 울림" 미리보기, 알림 채널(앱·텔레그램), 만료·반복, 하루 한도
  - 외부 MCP 쓰기 확인 (외부 계정 변경·삭제)

## 2. 투자 (`portfolio`) — PortfolioPage · portfolio/* · NetWorthChart · ManualAssetEditor

- 상단: 제목 "투자", 부제(계좌 수·갱신 시각), 새로고침
- 총자산 카드: 큰 숫자, 전일 대비, 이번 달, 주식 평가손익, 기간 1개월/3개월/6개월/1년, 추이 차트(일부 누락 점, 계좌 구성 변경 점선), "입출금 포함 · 평일 16시 스냅샷"
- 자산 배분: 국내주식·해외주식·코인·현금성·기타 막대
- 계좌: 증권사별 금액·비중·상태(정상/일부 누락/조회 실패/제외), 누르면 그 계좌만 필터
- 보유 자산: 계좌별/종목별, 종목명·티커 검색, 종류 칩(전체·국내주식·해외주식·코인·직접 입력), 정렬(평가금액·수익률·이름), 현재가·평가금액·손익, 1달러 미만 코인 접기/펼치기
- 직접 입력 자산: 추가·수정·삭제 (이름, 종류: 예금·현금/연금/부동산/기타 투자/기타, 금액, 원/달러, 메모)
- 미체결 주문: 목록 + 주문 취소(확인 후)
- 화폐별: 원화·달러·코인(USDT 환산) + 예수금
- 시세 조회: 종목코드/티커 입력 → 현재가·전일 대비 → "챗에서 분석·주문 준비하기"

## 3. 일지 (`journal`) — JournalPage · journal/*

- 상단: "매매일지", [가져오기](계좌 체결), [기록](직접 기록)
- 기간 30일/90일/올해/전체, 종목·근거 검색, 칩(전체·근거 없음·매수·매도·체결 확인 전), 태그 필터
- 요약: 기간 안 매매 수(큰 숫자) · 기록 습관(근거를 적은 매매 / 손절가를 정한 매수 / 회고를 쓴 매매, "근거 없는 것만 보기") · 태그(누르면 그 태그만) · 감정 분포. **손익 계산 없음**
- 목록: 날짜별, 매수/매도, 종목, 수량@가격, 출처(직접·챗 주문·자동 매매; 계좌 체결은 표시 안 함), "근거를 적어 두세요", 체결 확인 전 / 체결 없이 끝남
- 기록 보기·고치기 시트: 체결 사실(계좌·날짜·주문·체결·수수료·슬리피지·실현손익·감시, 고칠 수 없음) + 근거·손절가·목표가·태그·감정(차분·확신·불안·조급·욕심·충동)·회고, 삭제
- 직접 기록 시트: 매수·매도, 종목코드·티커, 종목명, 수량, 평균 체결가, 날짜, 어디서, 통화, 수수료 + 위 기록 칸

## 4. 가계부 (`ledger`) — LedgerPage · ledger/* · LedgerSettings

- 가계부 선택(여러 개, 멤버 수·기본), 월 이동, 범위(전체/내 기록), [관리·초대], [기록 추가], 받은 초대 수락
- 이달 지출(큰 숫자) · 수입 · 예산 남음/초과 · 분류별 비중(누르면 그 분류만)
- 예산: 분류별 사용률 (예산 설정은 챗에서)
- 사람별 지출 (가계부 전체 기준)
- 내역: 가맹점·메모 검색, 분류 필터, 날짜별 묶음(그날 지출 합), 수입 표시, 챗 기록 표시
- 기록 추가·고치기 시트: 지출/수입, 금액, 가맹점·내용, 분류, 날짜, 메모, 삭제
- 가계부 관리: 새 가계부, 이름 바꾸기, 기본 가계부, 멤버·초대(ID), 초대 취소, 소유권 넘기기, 멤버 내보내기, 나가기, 삭제(이름 입력 확인), 백업

## 5. 설정 (`settings`) — SettingsPage · AccountSettings · McpSettings · mcp/* · WatchSettings

탭: **계정 · 연결 · MCP 서버 · 감시 · AI 모델 · 화면 · 관리자(env 계정만)**

- 계정: 비밀번호 바꾸기, 이 기기만 남기고 모두 로그아웃 (서버 설정 계정은 env 안내)
- 연결: 그룹별 키 — 증권(KIS)·증권(토스)·코인(Binance)·데이터(해외)·뉴스(네이버)·알림(텔레그램). 상태(준비됨/미설정), 출처(내 설정/서버 env), 새 값으로 교체, 내 설정 지우기, 텔레그램 연결 테스트. 저장 값은 다시 보이지 않음
- MCP 서버: 연결한 서버(상태·툴 수·연결/연결 테스트/삭제), 추가(이름·주소·인증: 없음/Bearer/OAuth), 툴 목록(서버 고르기·검색·판정 필터 바로 실행/확인 카드·다시 받기·파라미터)
- 감시: 감시 목록(알림만/자동 매매, 켜짐·꺼짐·만료·소진·오류, 다음 확인·마지막 발동), 일시정지·다시 켜기·삭제, 비상 정지, 자동 매매 하루 매수 한도(국장 원·미장 $·코인 USDT), 최근 이벤트. **만들기는 챗에서**
- AI 모델: 모델 선택, LLM 키(OpenRouter·Anthropic, 비우면 서버 기본)
- 화면: 테마(시스템/라이트/다크). *(실제 앱의 단축키·줄바꿈 항목은 사용자 요청으로 이 제안에서 제외)*
- 관리자: 초대 코드 발급(유효 기간 1·7·30일, 메모)·취소, 계정 목록(비활성화/다시 켜기/임시 비밀번호), 서버 DB·env·버전

## 제안에서 제외한 것 (실제 앱에 없음)

통합 크로스 도메인 타임라인 홈, 순자산 이벤트 마커, 트리맵, 손익 기여, 월별 현금흐름, 목표 비중, 감정×수익률 산점도, AI 복기, 지출 달력 히트맵, 키패드 입력, 플로팅 챗 버튼(FAB), 별도 알림 화면·가격 게이지, 위젯·라이브 액티비티·워치, 맥락 칩, 주문 수량 편집 화면·비중 시뮬레이션, 컨페티, 키보드 단축키·커맨드 팔레트.
